# EnglishUp

**EnglishUp** is a simple educational game developed with Unity 2D to help school students learn English vocabulary through interactive quizzes.

## About

The game allows students to practice English words by looking at images and choosing the correct Russian translation from four possible answers.

The project was created as part of a school project to demonstrate the development of an educational application using Unity and C#.

## Features

- 4 educational levels
- 5 questions in each level
- 20 vocabulary questions in total
- Image-based questions
- Four translation options for each question
- Instant answer feedback
- Score system
- Level progression and unlocking
- Ability to replay completed levels

## Levels

1. Fruits and Vegetables
2. Animals
3. Food and Drinks
4. Home and School

## Technologies

- Unity 2D
- C#
- TextMeshPro
- Unity UI
